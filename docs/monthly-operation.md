## 1. 月次の作業概要


## 2. 月初：精算対象月の切り替え

`EXPENSE_MONTH_MODE: 'fixed'`（デフォルト）の場合、毎月初めに設定値を更新します。

### 手順

1. [Google Apps Script](https://script.google.com/) を開き、対象プロジェクトを選択する
2. `Config.gs` を開く
3. `EXPENSE_MONTH_FIXED` の値を今月の年月に書き換える

```javascript
// 変更前（先月のまま）
EXPENSE_MONTH_FIXED: '2026-03',

// 変更後（今月に更新）
EXPENSE_MONTH_FIXED: '2026-04',
```

4. Ctrl+S（または Cmd+S）で保存する

> **`folder` モードを使う場合**：`EXPENSE_MONTH_MODE: 'folder'` に設定すると、`01_取込` フォルダの名前（`YYYY-MM` 形式）から精算対象月を自動取得します。月ごとに取込フォルダ名を変更する運用が必要です。

## 3. 日常：証憑のアップロードと確認

### 3-1. 証憑のアップロード

1. 経費証憑（レシート・領収書等）を撮影またはスキャンする
2. Google Drive モバイルアプリまたは Web ブラウザで `01_取込` フォルダを開く
3. 画像ファイル（JPEG / PNG / HEIC / WebP）をアップロードする

> GAS タイムトリガーが 10 分おきに実行されるため、アップロード後しばらく待つと自動処理されます。

### 3-2. 処理結果の確認

処理後、ファイルは以下のフォルダに移動されます。

| 移動先フォルダ | 意味 | 対応 |
|-------------|------|------|
| `02_処理済み` | 正常処理完了 | 内容を確認して経費申請へ |
| `03_要確認` | 登録済みだが内容の確認が必要 | 台帳の内容を確認・修正する |
| `04_エラー` | 処理失敗・未登録 | エラー内容に応じて対処する |

### 3-3. スプレッドシートの確認

「経費証憑台帳」シートを開き、登録内容を確認します。

- **Y 列（要確認フラグ）が `TRUE`** の行はOCR の信頼性が低い項目があります。Z 列の要確認理由を確認して、必要な列を手動で修正してください。
- **W 列（画像 URL）** のリンクから元の証憑画像を確認できます。
- **AA 列（備考）** は申請者が自由に入力できます。

## 4. 月中・月末：フォルダの対処

### 4-1. `03_要確認` フォルダのファイル

スプレッドシートには既に登録済みですが、内容の確認・修正が必要です。

1. `03_要確認` フォルダのファイルを確認する
2. ファイル名のプレフィックス（`yyyymmdd-要確認-`）から処理日を確認する
3. スプレッドシートで対応する行を探し（W 列の画像 URL で照合）、内容を確認・修正する
4. 確認・修正が完了したら、ファイルを `02_処理済み` フォルダへ移動する

> ファイル名の `yyyymmdd-要確認-` プレフィックスはそのまま残してください（手動確認の証跡として残ります）。

### 4-2. `04_エラー` フォルダのファイル

台帳への登録が行われていません。エラー内容を確認して対処します。

1. 「処理ログ」シートを開き、対象ファイル名の行を探す
2. D 列（メッセージ）でエラー内容を確認する
3. 下表に従って対処する

| エラーメッセージの末尾 | 対処方法 |
|---------------------|---------|
| `要再アップロード` / `要差替` | 鮮明な画像に差し替えて `01_取込` に再アップロード |
| `要確認` | 元の証憑を確認して、内容を手動でスプレッドシートに入力 |
| `要再実行` | ファイルを `01_取込` フォルダに戻し、次回トリガーを待つ |
| `管理者確認` | 担当管理者に連絡する |
| `Gemini API エラー` | しばらく待ってから `01_取込` に戻して再試行する |

4. 対応完了後、ファイルを `02_処理済み` フォルダへ移動する

詳細なエラー対応フローは [`docs/error-handling.md`](./error-handling.md) を参照してください。

## 5. 月末チェックリスト

月次の経費申請前に以下を確認します。

### スプレッドシート

- [ ] 「経費証憑台帳」の Y 列（要確認フラグ）に `TRUE` が残っていないか確認し、必要な修正を行う
- [ ] 今月分の全行に対して精算対象月（B 列）が正しく入っているか確認する
- [ ] 空白が多い行（OCR 読み取り不足）がないか確認する

### フォルダ

- [ ] `03_要確認` フォルダが空になっている（または確認済みのものだけ残っている）
- [ ] `04_エラー` フォルダが空になっている（または対応済みのものだけ残っている）
- [ ] `01_取込` フォルダが空になっている

### 経費申請

- [ ] スプレッドシートの内容をもとに経費申請書を作成・提出する
- [ ] 提出後、台帳の AA 列（備考）に申請日や申請番号をメモしておく（任意）
