## 2. Google Drive フォルダの作成

以下の 4 フォルダを Google Drive 上に作成します。同じ場所（同一の親フォルダ内）にまとめておくと管理しやすいです。

| フォルダ名 | 役割 |
|-----------|------|
| `01_取込` | 証憑画像をアップロードする取込口 |
| `02_処理済み` | 正常処理済みの証憑の格納先 |
| `03_要確認` | 要確認フラグ付きで登録された証憑の格納先 |
| `04_エラー` | 処理に失敗した証憑の格納先 |

### フォルダ ID の確認方法

1. Google Drive でフォルダを開く
2. ブラウザのアドレスバーを確認する
3. `https://drive.google.com/drive/folders/`**`XXXXXX`** の **`XXXXXX`** 部分がフォルダ ID

4 フォルダそれぞれの ID をメモしておいてください。

## 3. Google スプレッドシートの作成

### 3-1. スプレッドシートを新規作成する

1. Google スプレッドシートで新規ファイルを作成する
2. ファイル名を任意で設定する（例：「経費証憑台帳 2026」）

### 3-2. シートを準備する

スプレッドシート内に以下の 2 つのシートを作成します。

| シート名 | 用途 |
|---------|------|
| `経費証憑台帳` | OCR 抽出結果の登録先 |
| `処理ログ` | 処理結果・エラーの記録 |

> GAS が初回書き込み時に自動でシートを作成しますが、事前に用意しておくと列幅の調整などをあらかじめ行えます。

### 3-3. 経費証憑台帳のヘッダ行を設定する（任意）

1 行目に以下のヘッダを入力しておくと、データが入力されたときに見やすくなります。

| 列 | ヘッダ名 |
|----|---------|
| A | 処理日時 |
| B | 精算対象月 |
| C | 書類種別 |
| D | 利用日 |
| E | 発行日 |
| F | 支払先名 |
| G | 宛名 |
| H | 摘要 / 但し書き |
| I | 合計金額（税込） |
| J | 10%対象額 |
| K | 10%税額 |
| L | 8%対象額 |
| M | 8%税額 |
| N | 非課税額 |
| O | 税率不明額 |
| P | 主税率区分 |
| Q | 支払方法 |
| R | 書類番号 |
| S | 適格請求書発行事業者登録番号 |
| T | 住所 |
| U | 電話番号 |
| V | 申請者 |
| W | 画像 URL |
| X | OCR 抽出テキスト |
| Y | 要確認フラグ |
| Z | 要確認理由 |
| AA | 備考 |

### 3-4. スプレッドシート ID の確認方法

アドレスバーの URL から確認します。

```
https://docs.google.com/spreadsheets/d/XXXXXX/edit
```

`XXXXXX` の部分がスプレッドシート ID です。メモしておいてください。

## 4. Gemini API キーの取得

1. [Google AI Studio](https://aistudio.google.com/) にアクセスする
2. 右上の「Get API key」または「API キーを取得」をクリックする
3. 「Create API key」をクリックしてキーを生成する
4. 生成されたキーをコピーして**安全な場所にメモ**しておく

> API キーはソースコードに直接記述しないでください。手順 7 でスクリプトプロパティに設定します。

---

## 5. Google Apps Script プロジェクトの作成

### 5-1. プロジェクトを新規作成する

1. [Google Apps Script](https://script.google.com/) にアクセスする
2. 「新しいプロジェクト」をクリックする
3. プロジェクト名を設定する（例：「経費証憑 OCR ツール」）

### 5-2. ソースファイルを追加する

`src/` 配下の各ファイルの内容を GAS エディタに貼り付けます。

**追加するファイル（9 ファイル）：**

| GAS スクリプト名 | ソースファイル |
|----------------|-------------|
| `Config` | `src/Config.js` |
| `ParseService` | `src/ParseService.js` |
| `ValidationService` | `src/ValidationService.js` |
| `FileService` | `src/FileService.js` |
| `LogService` | `src/LogService.js` |
| `DriveService` | `src/DriveService.js` |
| `GeminiService` | `src/GeminiService.js` |
| `SheetsService` | `src/SheetsService.js` |
| `main` | `src/main.js` |

**手順：**

1. GAS エディタ左側のファイル一覧の「＋」をクリックし「スクリプト」を選択する
2. ファイル名を入力する（例：`Config`）
3. 自動で追加される `function myFunction() {}` を削除する
4. 対応するソースファイルの内容を全選択してペーストする
5. 手順 1〜4 を 9 ファイル分繰り返す

## 6. CONFIG の設定

`Config.gs`（GAS エディタ上）を開き、プレースホルダーを実際の値に書き換えます。

```javascript
const CONFIG = {
  // 手順 2 で確認した各フォルダの ID
  INTAKE_FOLDER_ID:       '01_取込フォルダのID',
  PROCESSED_FOLDER_ID:    '02_処理済みフォルダのID',
  NEEDS_REVIEW_FOLDER_ID: '03_要確認フォルダのID',
  ERROR_FOLDER_ID:        '04_エラーフォルダのID',

  // 手順 3-4 で確認したスプレッドシートの ID
  SPREADSHEET_ID: 'スプレッドシートのID',
  SHEET_NAME:     '経費証憑台帳',   // シート名を変更した場合のみ修正
  LOG_SHEET_NAME: '処理ログ',       // シート名を変更した場合のみ修正

  // 精算対象月の決定方式（詳細は月次運用手順書を参照）
  EXPENSE_MONTH_MODE:  'fixed',   // 'fixed' または 'folder'
  EXPENSE_MONTH_FIXED: '2026-04', // 今月の YYYY-MM に書き換える（毎月更新）

  // 申請者名またはメールアドレス
  APPLICANT_NAME: '自分の名前またはメールアドレス',

  MAX_FILES_PER_RUN: 10,                    // 通常は変更不要
  GEMINI_MODEL:      'gemini-2.5-flash-lite' // 通常は変更不要
};
```

> `GEMINI_API_KEY` はここには記述しません。手順 7 で設定します。

## 7. API キーのスクリプトプロパティ設定

1. GAS エディタ上部メニューの「プロジェクトの設定」（歯車アイコン）をクリックする
2. 「スクリプト プロパティ」セクションまでスクロールする
3. 「スクリプト プロパティを追加」をクリックする
4. 以下を入力して保存する

| プロパティ名 | 値 |
|------------|-----|
| `GEMINI_API_KEY` | 手順 4 で取得した API キー |

---

## 8. タイムトリガーの設定

1. GAS エディタ左側の時計アイコン（トリガー）をクリックする
2. 右下の「トリガーを追加」をクリックする
3. 以下のように設定する

| 項目 | 設定値 |
|------|-------|
| 実行する関数 | `main` |
| 実行するデプロイ | `Head` |
| イベントのソース | 時間主導型 |
| 時間ベースのトリガーのタイプ | 分ベースのタイマー |
| 時間の間隔 | 10 分おき（推奨）または任意の間隔 |

4. 「保存」をクリックする
5. Google アカウントの認証ダイアログが表示されたら「許可」をクリックする

## 9. 初回動作確認

### 9-1. テスト実行

1. `01_取込` フォルダにテスト用の証憑画像（JPEG/PNG）を 1 枚アップロードする
2. GAS エディタで `main` 関数を選択して「実行」ボタンをクリックする
3. 初回は権限の確認ダイアログが表示されるので「許可」をクリックする

### 9-2. 結果確認

| 確認箇所 | 正常時の状態 |
|---------|------------|
| スプレッドシート「経費証憑台帳」| 1 行データが追加されている |
| スプレッドシート「処理ログ」 | `成功` または `要確認` の行が追加されている |
| `02_処理済み` または `03_要確認` フォルダ | ファイルが移動・リネームされている |
| `01_取込` フォルダ | 空になっている |

### 9-3. エラーが発生した場合

- GAS エディタ左側の「実行数」をクリックしてエラー内容を確認する
- エラーの内容と対処方法は [`docs/troubleshooting.md`](./troubleshooting.md) を参照する
